# 30个台词来源样本

复现：node --import tsx scripts/audit-memory-sources.ts。工具使用临时独立 PGlite 数据库、30个不同匿名会话，经真实业务接口上传合成文字并运行准备任务。不会使用现有开发资料；结束关闭数据库并清理临时目录。

原始结果：memory-source-samples.json。每项保留输入、实际动作线索、生成台词、规划器版本和来源查询结果；不公开身份、会话凭据或私人资料。30次准备均完成，manifest 来源 ID 与该人物提交的 evidence 一致。

样本1–10覆盖肯定等待/修补，11–17否定，18–19分句肯定，20矛盾，21–25未支持的记忆，26–30恶意指令或要求虚构往事。已逐项读取实际输出：肯定映射等待/修补；否定与矛盾回退一般想象；恶意指令未进入台词。全部台词为现有三条当下情境表达，没有具体往事断言。

这是代理读取与自动来源匹配证据，不计为原文档A03的30个人工样本审核。样本不覆盖任意自然语言、音频转写错误或真人效果。跨用户读取和撤回竞态仍以各自数据库回归为证据。
