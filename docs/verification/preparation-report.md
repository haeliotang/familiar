# 准备任务汇总报告

只读命令：`DATABASE_URL=... node --import tsx scripts/report-preparations.ts`。使用服务管理器或本地环境设置连接串，不把凭据写入公开记录。报告只输出计数和数值，不输出人物、用户、记忆、录音、资源路径或任务标识。

报告纳入数据库中所有保留的准备任务及逐次尝试，包括失败、取消和重试；单列历史尝试缺少观测的数量。分别汇总发布数、当前可播放数、个性化等级、质量标记与降级数。已撤回发布不计入当前可播放。local_placeholder 不代表质量已通过。

耗时分别统计 worker 执行及任务创建到尝试结束的年龄 P50/P95，不包含上传、浏览器加载或播放，因此不冒充端到端首访指标。历史缺失年龄不补零。

只有全部已记录尝试都包含供应商费用时才汇总该项；本地零供应商费用不代表计算免费。计算、存储传输及单位有效相遇总成本保持 null，尚缺计费依据及质量判定。删除清理过的任务已不在数据库中，本报告不是跨删除保留的运营账本，也不能代替完整成本验收。

单元检查覆盖失败重试、一般想象、撤回、缺失费用与历史观测；准备任务集成检查以真实 PGlite 表、查询和发布过程验证汇总及排队年龄。

发布审核补充：部分历史尝试缺少指标、后续尝试费用为零的用例先复现总额误报为零，再修复为 null。只要存在缺失的历史尝试，就不把剩余费用汇总标为完整供应商总额。
