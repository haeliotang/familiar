# 本人录音核对接口

2026-09-30。新增 GET/POST /v1/assets/:id/audio-review，限所属会话、活跃人物、ready 本人录音，private/no-store。GET 返回当前核对结果及分析指纹；POST 提交同一分析指纹、标准音频 SHA-256、选段起止、subject（single_person/mixed/uncertain）与最多 500 字核对文本。

分析指纹复用已有 canonical JSON 编码并 SHA-256，包含当前全部模型观察；音频、选段或分析参数变化时旧确认读取为 null，旧提交 409/audio_observation_changed。保存前事务锁定人物及资产、再锁观察行，避免删除后的写回。review 存在 asset_audio_observations 新增 JSONB 列内，删除观察时一并清除，ready 健康检查包含该列。重复同内容不递增人物版本；改变核对增加版本，让已排队的旧资料准备重新检查。

single_person 仅代表用户对该选段的说明，不是模型识别身份；仅该选择且已有 measured 语音时长时计算核对文本的汉字速率，标记 user_confirmed_text，表示文字经确认，不代表节奏算法或真人效果通过。mixed/uncertain 不生成本人速率。核对文字不写入人物记忆 evidence，也未接入声音计划。

测试使用隔离 PGlite 和合成观察：确认、回读、重复幂等及人物版本、多主体禁用速率、501 字拒绝、异会话 GET/POST 拒绝、源指纹变化使旧确认失效、删除清空并拒绝后续确认。初组相关 7 项通过；新增分析指纹和健康检查后，核对/健康 3 项及类型检查通过。尚未进行实际 PostgreSQL 确认/删除竞争测试或浏览器操作，未新增用户核对界面，不能声称完整核对流程已交付。

## 资料页核对入口

新增 PersonAudioReview 页面：显示自动选段原录音时间，默认主体不确定，提供本人单人/多人选择、最多 500 字符识别文字核对及保存状态；返回资料后可以再次进入，恢复已保存内容。加载时调用已有本地分析，再读取当前确认和分析指纹；重新分析后旧指纹失效可提示重新核对。处理期间阻止资料继续提交，组件退出终止加载请求，迟到保存不更新已卸载页面。

构建通过（保留场景大包警告）。服务已停止旧进程并重启完成迁移。实际浏览器使用此前已有合成 general.wav（0–1.73 秒），选择多人分支并输入已知合成台词，保存后显示未生成本人语速估计；返回、刷新再进入，主体、文字及保存状态恢复。该“多人”选择只是分支测试，录音本身并不是多人。截图 person-audio-review.jpg。未验证真实多主体、长录音语速数字、浏览器错误/删除竞态或选段试听；当前要求用户参照原录音，片段播放器仍需补齐。声音计划尚未使用核对结果。

## 所选片段试听

新增 GET /v1/assets/:id/audio-review/clip?fingerprint=…，仅所属会话的 ready 本人录音可读；分析指纹不匹配返回 409。读取标准 WAV 后验证完整文件 SHA，再从同一字节缓冲解析 PCM16 单声道 16kHz，截取指定至多 30 秒，生成无额外元数据的 WAV，不公开源路径或新增磁盘文件。发送前再次检查人物/资产可读与分析指纹，迟到撤销拒绝返回；private/no-store。已交付给浏览器的字节无法通过事后删除收回。
