# 录音上传处理恢复

2026-09-30。使用已发布通用 Kokoro 合成 general.wav，无真实录音、无外部推理。

问题复现：音频分支缺少 ffprobe 或 ffmpeg 时把有效上传标为 rejected，删除原件。两种回归均先返回 422 失败。修复后启动工具报 ENOENT 时返回 503/audio_processor_unavailable，清除可能的输出文件并保留原件与 uploaded 状态；恢复工具后同一 complete 请求能转换为 WAV、仅保留最终文件。真实解码失败仍按 422/rejected 清理。

原照片状态区扩展为 AssetReview，包含照片、本人录音、记忆录音。uploaded 文件可重试 complete；ready 记忆录音且 reviewState pending 显示核对入口，避免从该区域直接跳过文字确认；其他已处理资料可继续进入相遇。处理期间沿用提交锁。无新增依赖。

验证：客户端错误提示和服务端相关测试共 23 项通过；构建通过（场景包仍有大包警告）。主应用在临时隐藏音频工具时上传合成录音，观察保留提示；返回及刷新后恢复等待处理状态。恢复正常本地服务后点同一重试按钮，列表变为已处理，出现核对按钮；点击进入真实本地 Whisper 转写，结果为“今天的風很好”，保留繁体识别结果供核对，没有自动确认或写入记忆证据。
