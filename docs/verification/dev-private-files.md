# 开发服务器私有目录隔离

2026-09-30。使用合成标记文件复现，未请求已有私人文件内容。

问题：Vite 原配置允许直接请求项目内 .local-assets 文件，首次回归实际返回 200/synthetic-private-marker，绕过媒体 API 的会话所有权检查。开发启动脚本还使用 --host 默认监听所有接口。

修复：开发服务器 fs.deny 增加 .local-assets、.local-db、.models 的递归拒绝规则，保留当前 Vite 默认的 .env、.env.*、证书和 .git 规则。server.host 与 pnpm dev 明确使用 127.0.0.1。已验证旧开发进程活跃后停止，并启动新服务；lsof 确认 TCP 127.0.0.1:5173 LISTEN。

回归：server/dev-files.test.ts 启动临时仅本机 Vite 服务，创建独立随机合成文件。三个目录及环境/证书样本，各检查普通静态路径、@fs 绝对文件路径、?raw 模块读取：15 个请求均 403，响应不含合成标记。公开通用 Kokoro WAV 请求 200。测试退出关闭服务器并仅移除本轮创建的文件。测试通过，构建通过，现有场景大包警告保留。

边界：此处修复开发静态服务绕过，未证明生产反向代理、CDN、对象存储、所有编码/符号链接绕过或 A09 的完整访问矩阵安全。开发测试需要本地监听权限；没有处理真实私人素材或扩大网络暴露。
