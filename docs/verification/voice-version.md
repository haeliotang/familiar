# 本地声音版本与内容绑定

2026-09-30：新 episode 的 audioPlan 保存 voiceId、voiceVersion 与 sha256。现有三句本地 Kokoro 合成音频复制到明确版本目录，保留来源清单与模型许可证。播放接口核对台词、音色、版本、指纹后读取保留的 WAV，并再次核对文件指纹。模型与运行库更新不会触发旧相遇重新合成。

## 证据

- 修改前：未知与缺失声音版本都返回 200；新增两项回归测试实际失败。
- 修改后：5 项声音接口测试通过，涵盖版本拒绝、读取期间访问撤销和实际保留音频返回。
- 3 项音频资源测试读取每句真实 WAV；修改一个字节后校验拒绝。
- 9 项业务 API 测试通过，新相遇保存声音版本与等待台词指纹。共 17 项。
- 生产构建通过；仍存在场景文件大于 500 kB 的提醒。
- 重启真实本地 API 后，合成测试资料→相遇→声音接口返回 200，107032 字节音频的指纹与 manifest 相同；随后 DELETE 返回 202。
- 第一轮验收脚本为无正文请求附 JSON Content-Type，导致请求被拒绝。修正后成功。第一轮遗留的唯一合成测试人物与记忆，在停服后核对精确测试文本、仅一条记忆、无素材、无相遇后清理；本地 API 已恢复。

## 边界

只有三句固定台词和一种音色，未新增声音特征迁移能力。缺失声音版本的旧相遇拒绝声音读取，未追补或改写历史记录。服务端接口校验了返回音频，未新增浏览器试听、真机音画偏移或用户熟悉感证据。测试未证明完整 A04/A06，也未新增 PostgreSQL 容器验证。后续支持更多版本须保留旧版本目录及清单；当前仅支持 v1。
