# 记忆线索否定与矛盾处理

日期：2026-09-30。

先运行新增回归，八条明确否定记忆被旧关键词规则映射为正向动作，另一个跨句测试也失败，共九项失败。修复把文本按标点和转折词分句；同类线索所在句包含否定或低频措辞时不作为肯定证据，同类正反矛盾也不采用。独立肯定的另一行为仍可选用。

新相遇使用 memory-cue-template-v4。已存 evidence 的旧 cue 可能来自错误规则，因此同步和持久创建在新生成时根据原文重判；不改写历史 episode 的 manifest、人物/声音资源或已保存种子。新增任务默认版本和实际执行版本同步更新。

首轮修复后 encounter 十三项、API 二十项、准备任务八项共四十一项通过，构建通过。随后专项测试刻意把否定原文的历史 evidence cue 写成 repair，确认同步与持久两条创建路线都仍输出 general/v4；类型检查通过。

边界：这仍是保守的模板解析，不是完整中文理解。同句的其他否定、双重否定、引语、主体转换、复杂时间关系可能退回一般想象，不能宣称所有个性化线索归属已正确。既有历史误判相遇保持原记录，可由现有撤回/移除入口纠正，不在后台改写用户回看。
