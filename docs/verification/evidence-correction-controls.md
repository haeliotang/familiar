# 无个人线索场景的纠正操作

2026-10-01。此前非示例相遇始终显示“这个细节不对”，但撤回处理在缺少 evidenceId 时直接返回，一般想象场景因此出现可点击却无响应的按钮。

将该按钮提取为 EvidenceCorrection，缺少 evidenceId 时不显示；存在绑定线索时保留原撤回回调，提交中及撤回后禁用。一般场景的重看、移除回看和再次相遇保持可用。

先以原显示行为运行回归测试，缺少线索的用例失败；加入条件后，三个按钮渲染用例与七个历史记录转换用例全部通过。构建通过，仍有场景大包警告。浏览器打开已有合成照片生成的一般相遇，确认人物及语音准备完成，并且纠正按钮不出现；截图 generic-correction-controls.jpg。

本轮未在浏览器中实际撤回新的记忆线索；渲染检查不替代服务端撤回行为测试。没有上传真实私人资料。
