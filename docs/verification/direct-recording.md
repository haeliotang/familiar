# 直接录音入口

2026-09-30。补齐文档 2.3 的浏览器直接录制入口，来源分为“那个人本人的录音”和“我讲述的记忆”。按原有来源分别设置 deceasedAudio/memoryAudio，进入既有上传、标准化及记忆文字核对流程。

只有主动点击录制按钮才请求麦克风；结束录制生成本地 File，点击去看看才上传。取消丢弃本次数据；退出释放流；权限请求迟到时释放获得的流。录制期间锁住相遇提交、历史入口、其他录音及文件选择。自动在 180 秒停止，超过 30 MB 拒绝本次录制；编码失败不提交残缺文件。按浏览器支持选择 WebM/MP4/Ogg，去除 codec 参数作为上传 MIME，保留编码器 stop 前最后一个 dataavailable 块。权限拒绝和不支持录制时提示上传文件。

测试：7 项模拟 MediaRecorder 行为测试覆盖最终块、取消、时长限制、超大小、无可用格式、启动失败、编码失败及资源/计时器释放；与客户端 API 测试合计 16 项通过。构建通过，既有场景大包提示仍在。浏览器实际检查两个来源入口显示，截图 direct-recording-entry.jpg。

边界：没有授权实际采集麦克风声音，本轮未点击录制按钮或接受麦克风权限。模拟设备不证明真实浏览器编码、iOS 权限、手机中断恢复或实际端到端录音时长正确；这些仍需真实设备验收。没有为页面演示自动确认前一轮合成转写，而是明确跳过。

## 实际浏览器合成编码与上传

新增开发验证页 scripts/verify-direct-recording.html：AudioContext 生成 440Hz 合成音，经 MediaStreamDestination 与真实 MediaRecorder 编码；没有调用 getUserMedia。复用 recordAudio，检查可解码文件、末段 RMS、音轨结束，再创建一次性测试人物完成上传/标准化，最终提交删除。

首次实际上传返回 422，随后固定流式 WebM 回归样本复现：有音频流，但 ffprobe JSON 不包含 format.duration。旧流程将未知时长当成无效。修复允许未知容器时长进入受限解码，ffmpeg 最多输出 181 秒，再检查标准化 PCM WAV 实际时长必须在 (0,180]。缺时长两秒样本成功，缺时长 181 秒样本拒绝且清除原件和输出。此前已知过长输入仍提前拒绝。

相关录音/API/服务端 32 项测试通过，构建通过。实际浏览器复验：audio/webm、26259 字节、解码 1.62 秒、末段 RMS 0.10577092829316787、tracksEnded true、标准化 ready；临时人物已提交删除。截图 direct-recording-before.jpg、direct-recording-native.jpg。

边界更新：现已有实际浏览器合成编码和 API 标准化证据，仍没有真实麦克风采集或 iOS 证据。定时约两秒而实际解码 1.62 秒，尚未定位时长差，不宣称无截断或时间精度通过；末段 RMS 只证明所测片段有合成音。需继续检查编码启动延迟/音频时钟和实际设备录制。没有据此通过 A01/A06。

## 结束录制竞态与时钟测量

后续发现：MediaRecorder.stop 将状态立即改为 inactive，但最后 dataavailable/onstop 异步到达。连续点击结束会让旧实现第二次 stop 提前 complete，漏掉最后音频块；第一次 stop 也过早释放流。新增异步回归先失败，修复为 stopping 状态去重，正常结束等待 onstop 后释放音轨；取消和失败仍立即释放。停止等待期间取消回归验证丢弃文件且不保持麦克风占用。

录音与客户端相关测试 18 项通过（recordAudio 9 项）。生产构建通过。首轮新时钟测量：墙钟 2.0014 秒，AudioContext 1.84018 秒，解码文件 1.8 秒。此证据说明测试中的音频源时钟与墙钟推进不同，不能把整个时长差都归因于文件截断。

验证页改为按音频源时钟达到两秒再停止，墙钟十秒作为测试失败保护；接受解码 1.9–2.2 秒且与源时钟相差不超过 100ms。实际单次结果：源时钟 2.0143310658 秒，解码 1.9799773243 秒（差约 34.4ms），墙钟 2.5043 秒；末段 RMS 0.105858，音轨结束，实际上传标准化 ready。截图 direct-recording-clock.jpg。此测量条件写在开发验证页，未改变产品的 180 秒限制。

边界：已修复明确的异步停止缺块竞态，并区分墙钟/合成音频时钟。没有证明麦克风硬件、所有浏览器、长录音、真实设备无截断，也没有完成 A06 的 P95 同步测量。音频源时钟为何在当前后台浏览器里慢于墙钟仍未独立定位。
