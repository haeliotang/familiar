# 本地语音活动检测

2026-09-30。文档 321–322 行要求语速范围和停顿，音高由新身份决定。本次新增 Silero VAD v4 语音活动检测，为后续节奏提取提供基础，没有进行音高迁移或原声模仿。

模型来源、MIT 许可与固定指纹见 dependency-lock.md；运行库复用 sherpa-onnx-node。安装脚本固定 v4.0 权重并校验 SHA-256。本地依赖预检新增模型，当前 28 项全部通过。

observeAudioFile 在既有最高能量选段（最多 30 秒）内运行真实模型，保存绝对时间的 speechIntervals、speechDurationSec、相邻语音间 pauses 与 internalPauseRatio。只统计首段开始至末段结束内的停顿，不将录音首尾静音当作说话习惯。阈值 0.5，最短语音/安静 0.25 秒，512 样本窗口，CPU 单线程。无语音时比例 null；模型缺失、指纹不匹配或运行异常明确 status=unavailable，仍保留已有信号观测。记录仍绑定原资料及标准 WAV 指纹，沿用私有观察表和删除流程。

真实本地模型测试通过：3 秒静音无语音；两段已有 Kokoro 合成台词加一秒中间静音，识别两段及中间停顿，绝对时间落在选段内；拒绝非 16kHz、超过 30 秒和 NaN 输入。音频 API 测试实际归一化 WAV 后保存 measured 与正语音时长。本轮三组 17 项测试通过；补强 API 保存结果断言后，语音活动与音频 API 共 9 项再次通过，类型检查通过。

局限：选段仍按能量，尚未改成最大有效且可归属语音；VAD 不区分说话者，subjectAttribution 仍 unverified；阈值可能误判音乐/噪声；没有真实录音质量、语速估计、句尾节奏或新声音的节奏迁移证据。新字段保存在私有观察中，尚未进入 episode 声音计划。现有服务需要重启才能加载新代码。本轮未重新运行 PostgreSQL；前一轮 36 项结果不代表本次新增推理已通过该数据库。

## 异常与来源时间边界补验

随后补测选段起点 NaN、Infinity 与负值：先复现检测函数错误返回 measured，再增加入口拒绝条件，回归通过。新增独立合成 16kHz PCM WAV 测试，令语音检测抛出受控模型不可用错误，确认 speechActivity 为 unavailable（没有虚构空语音结果）、原始 WAV 字节不变、SHA-256 与信号观测仍保存。为测试复用现有分析注入方式，observeAudioFile 可注入检测函数；正常调用仍使用固定本地模型。10 项相关测试与类型检查通过。本次未真实移除模型或破坏其文件，未验证浏览器错误提示。

## 全录音扫描与语音覆盖选段

随后将 VAD 输入上限调整为 180 秒并逐块取出检测结果，避免仅扫描原能量选段而漏掉后段语音。observeAudioFile 先扫描全录音，再按 20ms 网格选择语音覆盖时长最大的连续至多 30 秒，同分取最早；在所选窗口再次检测并计算内部停顿，保留原录音的绝对时间。私有观察新增 selectionMethod=max_speech_coverage_v1；无语音或检测异常仍用 bounded_energy_v1。signal-window-v1 表示既有 RMS 信号统计，不表示语音检测版本。episode 目前只保留选段与指纹，完整选择方法和语音观察留在私有观察表，后续声音计划仍待扩展。

11 项相关测试通过，进一步补强真实模型测试：80 秒合成录音在 50 秒后放置两段台词，扫描检出两段，所选窗口包含它们且不超过 30 秒；该测试文件 4 项再次通过，类型检查通过。此证据不覆盖 180 秒压力耗时、真实噪声、多主体归属或首访 40/60 秒指标。全段扫描后重复初始化窗口检测会增加本地处理时间，尚需实际首访测量。
