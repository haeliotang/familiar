# 本地运行依赖预检

日期：2026-09-30。

从项目根目录运行 `pnpm check:local`。输出 JSON；全部通过返回退出码 0，否则返回 1。不下载模型、不访问供应商、不读取用户资料，不执行推理。可在启动本地 API 或部署候选版本前运行。

当前 27 项：ffmpeg、ffprobe、heif-convert 执行版本命令（每个最多 5 秒）；两套角色各四项资源与六个预制语音的 SHA-256；Kokoro 模型和 Whisper 编解码器 SHA-256；Kokoro 辅助文件/目录及 Whisper tokens 存在性。固定模型指纹对应 dependency-lock.md，角色及语音指纹使用现有运行清单。

本机实测 27 项全部通过，结果保存于 local-runtime-check.json。另在 /private/tmp 工作目录运行同一脚本：工具三项通过，资源 24 项缺失，ok=false 且退出码 1，没有修改实际项目资源。

边界：辅助词典/voices/tokens 仅验证非空文件，目录仅验证类型，未锁定全部内容；版本命令成功不保证能处理每个文件。当前只覆盖两套候选角色和已生成语音，未证明六身份、十二动作、六场景发布门，也不证明声音自然度、实际 ASR 准确率、CPU 性能、数据库、磁盘写权限或真实上线完成。已安装模型仍需现有实际推理验证。
