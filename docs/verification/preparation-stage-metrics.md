## 2026-10-01：加入任务等待年龄

每次尝试新增 `jobAgeAtClaimMs` 与 `jobAgeAtFinishMs`，分别为数据库中的创建时间至领取、创建时间至结束前记录指标的时间。使用数据库 `clock_timestamp()`，不依赖浏览器时钟或应用进程启动时间；领取失败前的内部错误可保留 null 的领取年龄。重试的任务年龄包含此前尝试，不能当作单次纯排队时长。

这两个数字包含数据库锁等待；`durationMs` 仍为 worker 开始后的单调时钟耗时，二者重叠，不能直接相加。结束年龄在写入终态和提交前测量，不含最终提交与客户端播放加载，不是完整首访时延。

新增回归先失败（等待字段缺失），再通过：人工把测试任务的数据库创建时间前移五秒，关闭服务后由 worker 处理，确认年龄保留五秒等待且与执行时长分开。准备与本地负载检查共 11 项通过，构建通过。多进程崩溃时尚不能保存完整的中断尝试指标，A12 仍未全通过。

随后在临时 PostgreSQL 17 容器中运行负载与保留语音发布测试：24 项通过、无跳过。包含本地/真实数据库 20 客户端负载以及音频事务回滚、删除和读取竞态。负载用例确认任务领取/结束年龄为非负且顺序一致。临时容器在验证后关闭并自动移除。
