# 主场景播放生命周期验证

2026-09-30。本地合成资料；无外部推理调用。

主场景复用 samplePlayback，统一台词、风声与播放时间。返回时同步 dispose，使尚在解锁或继续的请求失效，再关闭 AudioContext；主场景操作编号阻止旧请求更新页面，重复点击锁防止并发开始、暂停和重播。三秒解锁计时器在操作结束后清除，失败清除声源并保留无声观看入口。

回归证据：新增 dispose 待解锁用例先因缺少 dispose 失败，实现后通过。继续期间 dispose 用例验证不会重新进入 playing，声源与风声停止。相关播放和人物时间轴测试共 12 项通过，构建通过。场景包约 602 KB，仍有大包提示。

浏览器证据：主应用示例点击开启声音后显示暂停；暂停时 data-seconds 为 18.50049886621315，下一次检查保持完全相同；继续恢复暂停按钮；从头看归零并恢复开启声音按钮；再次开始后返回进入首页。截图 main-audio-restart.jpg 保存归零后的主页面。

边界：浏览器未强制制造待解锁退出竞态，该边界由控制器回归测试覆盖；未进行扬声器试听、音画偏移测量、真机性能或完整 75 秒结束验证，本轮未重跑 PostgreSQL 测试。
