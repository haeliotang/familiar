# 观看中关闭声音

原文档A15要求可关声；此前只有暂停或语音不可用时的静默分支，缺少主动开关。本次新增“关闭声音 / 开启声音”，台词空间声和环境风声都通过同一个输出增益节点。关声将该节点增益设为0，恢复为1；不停止声音源、不创建新的语音、不修改时间轴。退出断开输出并关闭上下文；新相遇重新开启默认状态。

新增共享输出回归先失败，修复后与播放生命周期、监听者方向检查共8项通过。构建通过。实际浏览器在女性修补审核页启动后关闭声音，按钮切换为开启声音，data-seconds从0.352推进到15.707秒；再次开启后进度继续到16秒，没有回到起点。截图 sound-off-playback.jpg。这证明按钮和进度切换，未采集扬声器输出，不宣称实际同步阈值通过。

同轮已有空间声音审核页实际OfflineAudioContext渲染通过：左右声源分别对应左右声道较强，近距离双声道RMS约0.691、远距离约0.319。截图 spatial-audio-current.jpg。这是声道方向和距离衰减验证，不是硬件延迟测量。
