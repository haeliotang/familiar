# 渲染帧测量入口

场景审核页 scripts/verify-scenes.html（不加 close=1）提供开始记录、结束并下载 JSON。记录实际 Scene 的 renderer.render 返回后时间，而非另外启动一条空 RAF。不会上传报告或读取私人资料。

每帧原始时间、页面是否可见、播放状态，以及帧间隔、记录时长、≤33.3ms 比例、>500ms 冻结数量随报告导出。报告带浏览器 userAgent、窗口大小、像素比、场景、人物版本、表演版本、种子和线索。测量中禁用场景切换；退出保持可用，退出期间没有渲染采样。需单独记录退出/重进情况。

至少90秒、可见采样、95%间隔≤33.3ms且无>500ms冻结，仅产生帧阈值布尔值。报告包含暂停与结束后停留，不证明90秒持续动作；不是GPU计时、音画同步或端到端首访速度。75秒结束后的15秒停留必须按此范围披露，不能写成90秒动画循环验收。页面隐藏发生在两次采样间时不能仅凭采样可见性排除，应保持前台并人工记录中断。

三项合成时间戳测试通过，覆盖不足时长、90秒边界、冻结、隐藏与原始播放状态保留。构建通过。尚无手机真机导出报告；工具可用性和桌面样本均不替代A07验收。

浏览器初次检查确认记录按钮进入运行状态、场景切换禁用、人物和语音就绪，截图 render-frame-recording.jpg。结束并下载的观测等待未返回文件；随后该标签仍在库存中，但连接读取超时，因此下载未确认，也不推断测量已经终止。后续增加结束报告在页面中的只读文本展示，供直接核对或复制原始数据；该展示构建通过，浏览器显示尚待验证。没有采集到可用于帧率结论的实际报告。
