## 运行

环境要求：Node.js 22、pnpm 10.32.1、ffmpeg/ffprobe，以及照片 HEIC 转换使用的 heif-convert。macOS 可安装 `brew install ffmpeg libheif`；Ubuntu 24.04 使用 `sudo apt-get install ffmpeg libheif-examples`。本地模型免费、无需账户，首次下载后可离线运行。

```sh
pnpm install --frozen-lockfile
sh scripts/install-local-voice.sh
sh scripts/install-local-asr.sh
sh scripts/install-local-vad.sh
pnpm check:local
pnpm dev:local-api
pnpm dev
pnpm test
pnpm build
python3 scripts/verify-local-restart.py
python3 scripts/verify-local-restart.py --with-memory-audio
```

分别在两个终端启动本地 API 和网页。打开开发服务显示的本机地址。输入一句**合成测试记忆**可生成一段 75 秒场景；也可进入无个人资料的示例。本地 API 使用 `.local-db/` 内的嵌入式 PostgreSQL，刷新后从数据库读取历史记录。删除入口会清除记忆正文并封锁对应相遇。媒体处理需要本机 `ffmpeg` 与 `ffprobe`。

当前三种模板台词已经由本地 Kokoro 合成，版本音频保存在 `public/assets/voices/kokoro-zh-zm009-v1/`；播放接口按相遇记录核对版本与 SHA-256，再返回相同字节，无需每次重新合成。相遇页面准备音频后显示“开启声音并开始”，在第 43 秒按同一音频时钟播放；不可用时提供无声观看。若要重新制作台词，可运行 `sh scripts/install-local-voice.sh` 安装模型，再使用样片制作脚本。脚本下载约 140 MB、校验压缩包并解压至 `.models/`，运行库为 `sherpa-onnx-node`。无需供应商账户，模型包附 Apache-2.0 许可证；新增音频须发布新版本并更新清单，不覆盖已记录版本。

正式部署尚需单独验证：设置 `DATABASE_URL` 后执行 `pnpm db:migrate` 和 `pnpm dev:api`。本地嵌入式数据库仅供开发测试；不要把当前原型用于真实私人资料。

PostgreSQL 服务还必须设置绝对路径的 `ASSET_DIR`；缺失时启动会失败。部署启动使用 `pnpm start`，不自动读取 `.env`。准备与回滚步骤见 [部署说明](docs/deployment.md)，正式发布演练仍未完成。

本地转写基线：`sh scripts/install-local-asr.sh` 下载官方 sherpa-onnx Whisper tiny 多语言模型（压缩包约 110 MB，SHA-256 校验），`node --import tsx scripts/verify-local-asr.ts` 使用已有的 `.models/kokoro-general.wav` 合成短句验证。Whisper 代码与权重采用 MIT 许可，来源为 https://github.com/openai/whisper 。模型无需外部账户；已接入上传后的转写核对页面，确认后才生成可用线索。

## 已实现

- React 页面与 Three.js 风格化场景，包含行走、停步、回头等有限动作及字幕时间轴。
- 三维代码在进入相遇时按需加载，入口脚本由约 718 KB 降至 235 KB（gzip 由约 197 KB 降至 75 KB）；显示加载状态，失败时可返回或重新加载。浏览器验证示例由加载提示进入场景与声音准备完成状态。此为构建体积和桌面浏览器证据，尚非手机性能验收。
- 基础环境声采用本地生成的滤波噪声作为轻风背景，无外部音频下载；与台词共用音频时钟，台词前降低背景音量、结束后恢复，场景结束淡出。暂停冻结音频时钟，重看与退出释放环境声节点。浏览器验证开启、暂停、重看操作；尚无音质试听、空间声或真机同步证据。
- 场景退出释放嵌套网格的全部几何与材质，共享对象只释放一次，并释放灯光阴影贴图、清空场景引用。单元测试覆盖共享几何、材质数组与阴影渲染目标的释放事件；不代表已完成真实设备连续 50 次体验或显存测量。
- 占位人物增加肩肘髋膝关节与四肢，按现有时间轴摆动行走、回头等待或抬手修补，结束段继续行走。三类线索各采样 751 个时点，验证双脚包围盒不穿过平地；浏览器检查行走段可见四肢并能暂停。仍是程序生成的原型，未提供正式 GLB 身份、蒙皮、接触动画或自然步态验收。
- “等待同行者”“修补物件”两类明确文字线索的规则映射；其他输入只生成一般想象场景。
- 服务端相遇记录、回看、再相遇和删除。
- 线索映射与相遇版本的基础测试。
- Fastify API 骨架：匿名会话、人物、文字线索、幂等的原型相遇、本人读取与删除；PostgreSQL 表与迁移脚本。原型相遇标为 `prototype`，不会冒称真实资产已经准备好。
- 使用嵌入式 PostgreSQL 跑通迁移 SQL 与 API 测试，覆盖跨会话隔离、重复请求和删除后的资料清除；网页已连接本地 API，浏览器验证了创建、再次相遇、刷新回看。
- 本地数据库适配器在事务期间独占连接，避免其他请求读取未提交数据或交叉执行事务；测试复现并修复了未提交数据泄露，也验证同时提交同键请求只生成一次相遇。本地请求因此会排队，不能据此估算正式数据库吞吐。
- 线索纠正闭环：撤回后未来相遇不再使用该线索，旧回看显示撤回标记，用户可以移除旧回看。
- 可跳过的体验反馈：记录是否联想到那个人、体验问题及一句补充；回看后可修改，同次相遇只保留一条当前反馈。本人鉴权，删除人物资料时清除对应反馈。
- 删除进度保存在数据库：页面查询待处理或已完成状态，清理失败会每分钟重试，服务启动时继续处理。重复删除返回同一任务；没有相遇记录的资料也可删除。测试覆盖文件清理受阻、跨会话拒绝、重复提交以及服务重启后的清理恢复。
- 运行服务验证：更新本地 API 后，页面读取删除进度不再报错；独立合成会话验证无相遇人物的删除、完成状态与重复删除复用同一任务，最终无活跃人物。已有页面资料未用于此次删除测试。
- API 响应 SIGINT/SIGTERM 时先关闭服务、等待请求与清理任务，再关闭数据库。独立临时目录的进程测试覆盖两种信号正常退出、重启后会话和人物恢复、恢复后删除完成；验证脚本自动清理临时进程和目录。此测试尚未覆盖强制杀进程或正式部署回滚。
- `verify-local-restart.py --with-memory-audio` 进一步使用已有合成录音验证真实本地链路：上传、ffmpeg 转换、Whisper 实际转写、修改确认、证据关联相遇、重启恢复转写与确认状态、删除后文件为空且转写返回 404。未确认录音生成的场景不引用证据。临时服务和目录自动清理；本测试不覆盖浏览器文件选择或真人录音质量。
- 本地记忆录音转写接口：`GET/POST /v1/assets/:id/transcription` 仅接受本人会话内已转换的 `user_memory_audio`；保留来源资产、模型版本与分段时间，重复请求复用结果。本人录音不会走这个记忆接口；转写不会自动写入人物线索。每个服务实例只运行一个转写请求，忙碌时返回 429。保存前事务检查人物与录音仍可用，删除人物时立即清除转写正文。
- 转写接口测试用受控识别结果验证跨会话隔离、来源区分、重复处理、忙碌拒绝与删除途中迟到结果丢弃；模型真实推理另由合成短句验证。页面确认、分布式任务调度、识别质量和完整 PostgreSQL 转写竞态仍待补齐。
- `POST /v1/assets/:id/transcription/confirm` 接受用户核对后的最多 500 字记忆，建立带录音来源和分段范围的证据。重复同文确认复用证据；修改内容建立新证据、停用旧内容并递增人物版本；已撤回或替换的旧确认请求不能恢复线索。测试覆盖确认前拒绝、输入拒绝、跨会话拒绝、去重、修改、撤回与删除。时间范围目前指向整份转写的分段，并非修改文字的精确字级对齐。
- 页面已接记忆录音核对流程：上传与转换完成后进入本机转写，用户可编辑确认或跳过，再生成相遇。上传回调测试覆盖转换失败不进入核对。构建通过；浏览器文件选择自动化异常，本次仅确认入口显示，完整上传→核对→相遇操作尚未浏览器验收。
- 录音核对状态现已持久化为待核对、已确认或已跳过；入口刷新时读取本人资料列表，恢复一份待核对录音。跳过请求幂等，不生成证据，也不覆盖已确认状态；删除后拒绝迟到跳过。接口测试覆盖状态恢复所需的列表字段与跳过隔离；浏览器刷新恢复尚未实测。
- 转写失败提示按已知服务错误码说明忙碌、未准备好、已撤回和本地模型不可用；未知或非 JSON 响应仅显示状态信息，不透传服务端正文。测试覆盖三种转写失败提示及非 JSON 错误降级。
- 临时 PostgreSQL 转写验证：同文并发确认返回同一证据且人物版本只增加一次；修改确认与人物删除并发后证据和转写正文均为空，后续确认被拒绝；识别暂停期间删除人物，再放行识别，迟到文字返回 404 且不保存。本组连同已有数据库测试共 10 项通过，临时容器已清理。模型输出受控，不能据此评价真实录音质量。
- 反馈验证：浏览器用合成反馈跑通保存与返回后恢复；本地 API 测试覆盖输入拒绝、跨会话拒绝与清除；临时 PostgreSQL 测试覆盖提交与删除并发后的零残留及迟到提交拒绝。
- 本地私有媒体 API：照片与两种音频来源分别建立上传意图；校验大小、所属会话与解码内容；照片转 JPEG 并移除原始元数据，音频转 16 kHz 单声道 WAV。损坏文件拒绝，人物删除后清理对应文件。本地文件位于忽略版本控制的 `.local-assets/`，没有公开下载路由。
- 使用临时官方 PostgreSQL 17 容器完成真实数据库集成测试，验证迁移、并发同键提交、跨会话拒绝、线索撤回和删除清理；测试后容器已停止并自动删除。
- 页面开放照片及两种来源的录音入口；本地 Kokoro 已按三种线索合成并保存模板台词，API 校验后返回 24 kHz WAV。相遇记录保存台词、开口时间、声音版本与指纹，语音资源经会话鉴权；删除或撤回后拒绝重新读取。语音与已上传录音无关。
- 语音生成结束后再次检查访问资格，拒绝生成期间已失效的相遇；受控延迟测试验证失效后返回 404、仍可访问时正常返回音频。此测试不等于完整数据库并发或流式传输撤销验证。
- 临时 PostgreSQL 中进一步验证三种实际状态变更：生成途中删除人物、撤回线索、移除回看；变更提交后才结束合成，三种迟到响应均为 404。该组及已有数据库测试共 6 项通过；测试后临时容器已停止并删除。已开始传输的音频和上传文件竞态尚未由这组测试覆盖。
